## **What it is**:

IoTWeaver is a complete IoT platform developed for real-time monitoring and control of industrial and commercial devices. With a modular and flexible architecture, the platform offers robust connectivity, advanced automation, and simplified integration with your systems.

## **Platform Architecture**:

The IoTWeaver platform consists of three main devices that work together:

- **Iris**: IoT gateway that connects mesh networks to the internet in large installations
- **Hecate**: Mesh network orchestrator that manages communication between multiple Hermes devices
- **Hermes**: Edge devices responsible for sensor data collection and actuation execution

## **Key Features**:

- **Self-Healing Mesh Network**: Mesh topology with redundancy and dynamic routing for maximum reliability
- **Lua Scripting**: Support for Lua scripts for custom automations and advanced behaviors
- **Webhook Integration**: Receive real-time data through configurable webhooks
- **REST API**: Remote device control through HTTP commands
- **Flexible Connectivity**: Support for direct Wi-Fi or through gateway for different installation scenarios
