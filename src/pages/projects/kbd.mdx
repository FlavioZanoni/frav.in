## **What it is**:

I built a custom mechanical keyboard with the Sofle layout kit, using an Arduino Pro Micro as the controller, and QMK firmware to program it. The keyboard features RGB backlighting, hot-swappable switches, and a compact 58 keys ortholinear layout. I designed a custom keymap to optimize my workflow, including layers for media control and navigation. The keyboard is housed in a sleek acrylic case with a minimalist design.

## **Why**:

Why not? split keyboard is the way to go!!
