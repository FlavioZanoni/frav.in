## **My role:**

As a Freelance Software Developer, I work with clients on full-stack development, tooling development, and consulting. I lead projects from architecture to delivery, focusing on AI-powered solutions and workflow automation.

Led development of an accessible e-book publishing system that uses AI to generate image descriptions. Implemented an extraction pipeline, AI analysis queue, and role-based review interface that reduced manual work by 90%. The system was subsequently offered as a subscription service.

### E-book Production ERP
Delivered an internal ERP-style workflow system for e-book production, mapping titles to production phases and enabling end-to-end tracking across the pipeline.

### AI Legal Assistant RAG Pipeline
Built core RAG (Retrieval Augmented Generation) pipeline for an AI legal assistant, including document ingestion, embedding generation, vector database setup, and retrieval/ranking logic for context assembly.
